# 跨界走私犯

## 何时使用

用户有两块不同来源的知识（两个 @ 页面，或粘贴两段文本），希望：

- 发现跨领域的隐藏结构相似
- 得到可落地的「偷师清单」，而非空洞励志
- 生成适合截图分享的「走私地图」

典型场景：设计展 × 智能制造讲座、创业大赛通知 × 心理学文章、峰会新闻 × 本专业课程页。

## 变量

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 货源 A | 文本 | （用户 @ 或粘贴） | 第一个领域/页面 |
| 货源 B | 文本 | （用户 @ 或粘贴） | 第二个领域/页面 |
| 走私目的 | 选项 | 竞赛灵感 | `竞赛灵感` / `创业点子` / `论文选题` / `纯好玩` |

## 执行前

1. 读取 **货源 A**、**货源 B** 的正文（各至少 100 字）。不足则提示补充。
2. 分别提取每边的：**领域标签**、**3 个关键词**、**核心方法/主张**（各 1 句）。

## Step 1 — 结构对齐

找出 A 与 B 之间 **1 个深层结构相似点**（不是表面关键词重合），例如：

- 「都是把隐性经验变成可复用流程」
- 「都在解决信息不对称下的协调问题」

用 2 句话说明，并各引用 A、B 中的一个具体表述。

## Step 2 — 走私品（三条技法）

列出 3 条可从 A **偷到** B（或反向）的具体技法：

```
技法 1：[名字] — 来自 [A/B] 的 [具体做法] → 在另一边可变成 [具体行动]
...
```

每条技法必须含**动词**（拆解/对齐/试错/策展…），禁止形容词堆砌。

## Step 3 — 走私地图（截图友好）

输出 ASCII 风格简图：

```
[领域 A 关键词] ──相似点──► [领域 B 关键词]
      │                           │
   技法1·2                      落地场景
      └──────────┬───────────────┘
            [走私目的] 下一步
```

## Step 4 — 根据走私目的给 1 个下一步

| 走私目的 | 输出 |
|----------|------|
| 竞赛灵感 | 一个可写进立项书的交叉题目（<=30 字） |
| 创业点子 | 一个最小验证动作（本周可完成） |
| 论文选题 | 一个可检索的交叉关键词对 |
| 纯好玩 | 一句适合发即刻的吐槽/洞察 |

## 输出格式

```
🚚 跨界走私报告
结构对齐：[Step 1]

📦 走私品
[Step 2 三条]

🗺️ 走私地图
[Step 3]

▶️ 下一步（[走私目的]）
[Step 4]

📸 分享版
「我把 [A关键词] 和 [B关键词] 对在一起，发现 [结构相似点一句话]。」
```

## 局限

- 需要用户主动提供两个货源；单页请用「苏格拉底 × 破壳」
- 类比不等于事实等价；技法需用户自行验证适用性
