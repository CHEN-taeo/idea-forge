# 截止日！通知页倒计时

## 是什么

在 `*.edu.cn` 通知**列表页**每条标题旁自动加上彩色倒计时标签：**还剩 X 天** / **今天截止** / **已过期**。

与破壳（Poke）后端 `poke-server/src/lib/deadline.js` 使用同一套日期解析规则，浏览器侧先看 deadline，导入破壳后卡片上继续显示分级截止信息。

## 适用页面

- 东华大学教务处通知：https://jw.dhu.edu.cn/tzgg/list1.htm
- 学校主页通知：https://www.dhu.edu.cn/tzgg/list1.htm
- 其他树维 CMS / 常见 `ul.list li a` 结构的 `.edu.cn` 列表页

**不适用**：详情页正文、非列表首页、需登录的后台。

## 颜色含义

| 标签 | 剩余天数 | 含义 |
|------|----------|------|
| 绿色 | >14 天 | 安全 |
| 橙色 | 8–14 天 | 注意 |
| 红色 | 3–7 天 | 紧急 |
| 深红脉冲 | 0–2 天 | 最后冲刺 |
| 灰色 | 解析不出 | 标题含「截止」但无具体日期 |

## 使用方法

1. Tabbit 新建 **脚本妙招**，粘贴 `script.js`
2. 打开上述通知列表页
3. 运行脚本 → 列表项右侧出现 ⏰ 标签
4. 截图 Before/After 用于广场封面

## 与破壳闭环

1. 脚本标出紧急项 → 点开详情
2. 运行 **破壳投喂格式化** 提示词 → 复制输出
3. 破壳小程序 **导入** → AI 结构化 + 信息差排序

## 局限

- 仅从**列表标题**解析日期；标题无日期时显示灰色或跳过
- 不同 CMS DOM 若无法匹配，需在控制台查看 `[poke-deadline-radar]` 日志
- 不修改原站数据，仅前端 DOM 装饰
