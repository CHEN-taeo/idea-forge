# 评论区情绪脱水机

## 是什么

在知乎、B站、新闻等**评论区**，把高情绪、低信息密度的回复折叠成 **🧽 脱水气泡**，一眼看清讨论的情绪结构，而不是被「哈哈哈」「破防了」淹没。

与破壳「信噪提纯」同一哲学：不是不让你看评论，而是先脱水面纱，再决定是否展开原文。

## 脱水规则（启发式）

| 信号 | 处理 |
|------|------|
| 玩梗、纯表情、超短附和 | 折叠为「情绪气泡」 |
| 含数据、日期、论证结构 | 保留原文 |
| 中等长度纯情绪 | 折叠为「支持+玩梗 · 原文 N 字」 |

点击气泡可展开/收起原文。

## 适用页面

- 知乎问题页评论区
- B站视频评论区（部分 DOM）
- 通用 `[class*="comment"]` 结构站点

**不适用**：微信网页版（DOM 封闭）、无评论的列表页。

## 使用方法

1. Tabbit 新建 **脚本妙招**，粘贴 `script.js`
2. 打开任意热门帖评论区
3. 运行脚本 → 右下角显示「脱水 N/M 条」
4. 截图 Before/After 发小红书（传播利器）

## 与「信息食谱」提示词配合

- 脚本：脱水**评论区**
- 提示词：诊断**正文**的信息成分
- 任务「苏格拉底」：对正文提**问题**

三条同一主题：**从信息过载到认知跃迁**。

## 局限

- 启发式规则，可能误伤短但有用的评论（可点击展开）
- 站点 DOM 变化需更新选择器
- 不上传、不存储任何评论内容
