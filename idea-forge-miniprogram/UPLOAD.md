# 炉边 · 微信小程序上传指南

AppID：`wx37b3449199acea3b`（见 `project.config.json`）

## 一、上传前检查

| 项 | 说明 |
|----|------|
| 拾念 | 纯本机存储，**无需后端**即可体验 |
| 名士围炉 | 需要 `GET/POST /api/ai/*`，无 Key 时走离线模板 |
| 入炉（多人） | 需要 **HTTPS + WSS** 的 `server.js`（Socket.IO） |

### 1. 配置线上 API（若要全功能）

编辑 `utils/config.js`：

```js
const PROD_SERVER_URL = 'https://你的域名';  // 不要末尾斜杠
```

将 `server.js` 部署到该域名（需支持 WebSocket）。本地可参考根目录 `npm run server`。

### 2. 微信公众平台域名

登录 [微信公众平台](https://mp.weixin.qq.com) → **开发** → **开发管理** → **开发设置** → **服务器域名**：

| 类型 | 示例 |
|------|------|
| request 合法域名 | `https://你的域名` |
| socket 合法域名 | `wss://你的域名` |

每月修改次数有限，先部署好再填。

### 3. 开发者工具本地设置

上传代码前在开发者工具确认：

- 详情 → 本地设置 → 上传时**可关闭**「不校验合法域名」（体验版真机才会走正式校验）
- 编译模式选「普通编译」

## 二（简）、上传步骤（微信开发者工具）

1. **导入项目**  
   目录选：`idea-forge-miniprogram/`（不是仓库根目录）

2. **编译预览**  
   - 拾念、名士围炉在模拟器走一遍  
   - 若已配 `PROD_SERVER_URL`，用手机扫「预览」二维码真机测

3. **上传**  
   顶部 **上传** → 填写版本号（如 `1.0.0`）和项目备注，例如：  
   > 炉边 v1.0：拾念、名士围炉、多人入炉；暖色编辑风 UI

4. **设为体验版**  
   mp.weixin.qq.com → **管理** → **版本管理** → 开发版本 → **选为体验版**  
   添加体验成员微信号，扫码即可试用（无需审核）。

5. **提交审核**（要公开发布时）  
   版本管理 → **提交审核**  
   - 类目：工具 / 效率 或 教育（按账号资质选）  
   - 测试账号：若需登录则说明「无需登录」  
   - 功能页面：首页、拾念、名士围炉  

### 审核说明可参考

> 炉边是一款讨论与承诺工具。用户可记录灵感（拾念）、与 AI 风格化嘉宾围炉论道（名士围炉），或创建房间与好友结构化讨论（入炉）。AI 嘉宾为风格演绎，页面已标注免责声明。拾念数据仅存用户本机。

## 三、仅上传、暂不部署后端

可以先把**体验版**发给自己人：

- **拾念**、**週火观照** 可完整使用  
- **名士围炉** 无 API 时用离线模板回复  
- **入炉** 需后端，会显示未连接  

适合先过审 UI、收文案反馈；全功能上线前务必配置 `PROD_SERVER_URL` 与域名。

---

## 四、真机调试局域网（开发用）

`utils/config.js` 开发环境默认 `127.0.0.1:3001` 仅模拟器可用。  
真机调试时临时改成电脑局域网 IP，例如：

```js
const DEV_SERVER_URL = 'http://192.168.1.100:3001';
```

并勾选「不校验合法域名」。

## 五、常见问题

| 现象 | 处理 |
|------|------|
| 未连接服务器 | 根目录 `npm run server`；或配置 `PROD_SERVER_URL` |
| 真机 request 失败 | 检查合法域名是否为 **https**，证书是否有效 |
| 入炉连不上 | 除 request 外还须配置 **socket 合法域名** |
| 上传后仍是旧 UI | 确认上传的是 `idea-forge-miniprogram` 目录最新代码 |
