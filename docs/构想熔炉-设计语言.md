# 构想熔炉 · 设计语言（Brand & Design Language）

> **状态**：v0.1 · 2026-06  
> **战略锚点**：[`破局之道-AI陪审团与预演战略.md`](./破局之道-AI陪审团与预演战略.md)  
> **适用**：Idea Forge 全产品（围炉 / 独思 / 围炉群英会 / 闪念 / 预演）

---

## 1. 一句话气质

**炉前预演，开口之前先想清楚。**

不是「又一个 AI 聊天 App」，不是「又一个会议白板」，而是：

> **在真人开口之前，让想法先经历一场有结构、有对抗、有承诺的围炉夜话。**

视觉气质：**东方夜话 × 现代思辨** — 炭火、墨色、宣纸，承载当代的讨论与求真。

---

## 2. 与《破局之道》的对应关系

| 战略概念 | 设计语言如何体现 |
|----------|------------------|
| **预演（Rehearsal）** | 首页主文案、流程命名、完成页「战斗报告」式收束 |
| **AI 陪审团 / 群英会** | 角色立绘有性格、场景是「围炉对坐」而非聊天列表 |
| **想法级工具** | 输入极简（闪念、一句话开场），不逼用户先建房间 |
| **Solo → Group 链路** | 视觉从「一人围炉」平滑过渡到「多人围炉」，同一套场景语言 |
| **想法战斗证书** | 导出/完成页像「炉前勘验书」，不是 generic 会议纪要 |
| **被认真对待** | 动效慢、留白多、AI 透明标注，不炫技 |

**产品要占领的词**：**预演**、**炉前**、**围炉**（不是 brainstorm、不是 chat）。

---

## 3. 美学人格：东方夜话 × 现代思辨

### 3.1 场景意象

```
深夜 · 一炉炭火 · 几人围坐 · 茶烟轻升 · 真话渐明
```

- **火**：唯一暖光源，所有角色面光来自炉心（不是霓虹边框）
- **墨**：背景与文字，像砚台与夜色，不是纯黑科技感
- **纸**：卡片与报告，像宣纸纤维，不是玻璃拟态塑料感
- **声**：讨论是「听见不同声音」，不是「收到 AI 回复」

### 3.2 我们要避免的「AI 默认皮」

| 避免 | 原因 |
|------|------|
| 高饱和橙 + 纯黑 + 强 blur 玻璃 | 2023–2024 通用 AI 皮肤，无品牌 |
| 满屏 spring 弹跳 | 像游戏 HUD，不像围炉 |
| 聊天泡泡列表为主视觉 | 像 ChatGPT，不像预演 |
| 写实名人肖像 | 法律与信任风险；用风格化 Q 版 / 水墨淡彩 |
| 排行榜 / 红心 / 连胜羞耻 | 与心理安全、求真相悖 |

## 5. 字体

| 层级 | 字体栈 | 用途 |
|------|--------|------|
| **Display** | LXGW WenKai, STKaiti, KaiTi, serif | 产品名、模式名、围炉标题 |
| **Body** | PingFang SC, Microsoft YaHei, system-ui, sans-serif | 正文、输入、按钮 |

规则：

- 标题用 Display，**字间距略宽**（`tracking-tight` ~ `tracking-wide` 按层级）
- 正文保持 15px 基准，**行高 ≥ 1.6**
- 不用全大写英文标题（不符合中文产品气质）

## 6. 材质与组件

### 6.1 卡片 `page-card`

- 底色：宣纸纤维感（极淡噪点可选）
- 边框：1px 墨金线，`rgba(232,165,75,0.12)`
- 圆角：`--radius` 12px，**不要过大胶囊**
- **减少** `backdrop-filter: blur` 作为主识别；围炉场景可用轻 blur 作输入区 `rt-composer`

### 6.2 围炉场景 `rt-scene-bg`

- 三层：墨底 → 侧面炉光晕染 → 顶部微弱烟霭
- 中央：**SVG 炭火**（`FireCore`），呼吸动画，**不用 🔥 emoji**
- 桌面：椭圆木纹感 radial-gradient，嘉宾光来自炉心方向

### 6.3 动效原则

| 场景 | 时长 | 感觉 |
|------|------|------|
| 页面进入 | 300–500ms | 入座，不弹跳 |
| 炉火 | 2.5–4s 循环 | 呼吸 |
| 发言中 | 1.5–2s | 光晕扩散，非爆炸 |
| 消息气泡 | spring 轻度 | 像递话，不像通知 |

**尊重** `prefers-reduced-motion`：炉火改静态、动效改 opacity。

## 7. 角色立绘规范（Q 版 · 水墨淡彩）

### 7.1 风格定位

- **2–2.5 头身 Q 版**，扁平插画风
- 参考气质：《中国奇谭》角色可读性 × 丰子恺线条的克制 × 游戏卡牌半身像
- **统一家族感**：同一描边粗细、同一光影逻辑（炉光从左下）

### 7.2 资产路径

```
public/personas/
  musk.png
  huang.png
  ...
  README.md   ← 生成与交付说明
```

代码：`PersonaPortrait` 优先加载 `/personas/{id}.png`，失败则回退 SVG 占位。

### 7.3 每角色 3 状态（设计师交付）

| 状态 | 文件名 | 表情 |
|------|--------|------|
| 默认 | `{id}.png` | 平和 |
| 思考 | `{id}-thinking.png` | 微皱眉（可选 v2） |
| 发言 | `{id}-speaking.png` | 开口（可选 v2） |

v1 只需默认态；思考/发言可用 CSS 光晕 + 缩放代替。

### 7.4 AI 生成 Prompt 方向（Midjourney 等）

统一后缀（与战略一致，偏东方而非日系 niji）：

```
chibi half-body character portrait, Chinese ink wash light color illustration,
flat clean shapes, warm firelight from below, soft round face,
game card art, transparent background, single character centered,
no text, no watermark --ar 1:1 --stylize 200
```

每个角色在此前缀后加 **服装/道具/气质** 描述（见 `public/personas/README.md`）。

**免责声明（界面固定）**：席位嘉宾为 AI 风格化演绎，不代表真实人物或其观点。

## 8. 信息架构与文案

### 8.1 首页层级（不稀释主功能）

1. **主 CTA**：预演 / 独思 / 群英会（想法还没成熟的人）
2. **次 CTA**：发起围炉（团队已准备好）
3. **轻入口**：记闪念（极低摩擦）
4. **更多**：加入房间、热座

### 8.2 核心文案（`brand.ts` 可 env 覆盖）

| Key | 默认中文 |
|-----|----------|
| `homePrompt` | 你有什么想法，还没告诉任何人？ |
| `rehearsalName` | 炉前预演 |
| `roundtableName` | 围炉群英会 |
| `slogan` | 让每次讨论，都有人领走一件事。 |
| `rehearsalTagline` | 开口之前，先让想法经受一轮预演。 |

### 8.3 完成页 · 想法战斗证书（目标形态）

```
炉前勘验书
─────────
议题：……
存活论点：2 条
被质询击穿：1 条
未解反对意见：……
☯ 14 天内验证：……
```

## 9. 体验闭环（设计驱动功能）

```text
闪念捕捉（极低摩擦）
    ↓
炉前预演 / 独思 / 群英会（AI 多声部）
    ↓
收束 + 假设清单 + 反对意见
    ↓
认领承诺（SMART · 14 天）
    ↓
回顾（炉前再审）
    ↓
多人围炉（带战斗报告入场）
```

每一环 UI 应让用户感到：**我在让想法变得更真，而不是在跟 AI 聊天。**
